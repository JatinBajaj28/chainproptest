# Vulnalyzer

**Open-Source Dependency Exploit Propagation Mapper**

Vulnalyzer traces transitive dependency trees across public repositories to identify
projects affected by CVEs, estimates exposure severity, and generates patch-request
issue text for maintainers — now with **AI-powered patch recommendations via Gemini**.

## Architecture

```
vulnalyzer/
├── vulnalyzer/
│   ├── core/           # Shared utilities: DB, version matching, models
│   ├── ingest/         # CVE ingestion from OSV
│   ├── scanner/        # Repository scanning engine
│   │   └── plugins/    # Per-ecosystem manifest parsers (npm, PyPI, Maven …)
│   ├── graph/          # Graph construction, metrics, and export
│   │   ├── patch_request.py   # Issue generator (+ AI-powered version)
│   │   └── ai_patches.py      # ✨ Gemini AI patch suggestions (NEW)
│   └── api/            # FastAPI routes
├── scripts/
│   └── generate_ai_patch.py  # ✨ AI patch CLI (NEW)
├── tests/
└── data/               # SQLite database lives here
```

## Quick Start

```bash
pip install -r requirements.txt

# 1. Ingest CVEs for a package
python scripts/ingest_cves.py --package lodash --ecosystem npm
python scripts/ingest_cves.py --package django  --ecosystem PyPI

# 2. Scan a single repo
python scripts/scan_repo.py --url https://github.com/timepassuser/vuln_test

# 3. Batch scan from a file
python scripts/batch_scan.py --file repos_to_scan.txt

# 4. Build / refresh the graph
python scripts/build_graph.py

# 5. Query the graph
python scripts/query_graph.py --cve GHSA-35jh-r3h4-6jhm
python scripts/query_graph.py --package lodash --ecosystem npm
python scripts/query_graph.py --repo https://github.com/timepassuser/vuln_test
```

## Graph Model

```
Repository ──USES──> PackageVersion ──INSTANCE_OF──> Package ──AFFECTED_BY──> Vulnerability
Repository ──EXPOSED_TO──> Vulnerability   (derived, for fast queries)
```

Nodes and edges are stored in SQLite (fully queryable without a graph DB).
A JSON export compatible with Obsidian / force-directed frontends is generated by
`build_graph.py`.

## Extending with new ecosystems

Add a file in `vulnalyzer/scanner/plugins/` that implements the `ManifestPlugin`
interface (see `plugins/base.py`).  The scanner auto-discovers all registered plugins.

## ✨ AI-Powered Patch Recommendations (NEW)

Vulnalyzer now integrates with **Google Gemini** (free API) to generate intelligent
patch recommendations for every vulnerable dependency found.

### What you get

For each vulnerable package, instead of just "Upgrade to v2.5.1", Gemini produces:

- **Recommended version** — the oldest version that patches all CVEs (conservative)
- **Upgrade strategy** — e.g. "Minimal patch bump", "Major version upgrade required"
- **Breaking changes** — what to watch out for when upgrading
- **Migration steps** — step-by-step instructions tailored to the ecosystem
- **Upgrade risk level** — low / medium / high

### Setup (free, 2 minutes)

1. Get a free Gemini API key at https://aistudio.google.com/app/apikey
2. Set the environment variable:

```bash
export GEMINI_API_KEY=AIza...
```

No extra Python libraries needed — uses Python's built-in `urllib`.

### CLI usage

```bash
# Scan + AI patch suggestions
python scripts/generate_ai_patch.py --repo https://github.com/owner/repo

# Save to a markdown file
python scripts/generate_ai_patch.py --repo https://github.com/owner/repo --output issue.md

# Basic mode (no AI, no API key needed)
python scripts/generate_ai_patch.py --repo https://github.com/owner/repo --no-ai
```

### API usage

```bash
# With AI recommendations (requires GEMINI_API_KEY)
curl "http://localhost:8000/api/patch-request?owner=timepassuser&repo=vuln_test&use_ai=true"

# Basic mode
curl "http://localhost:8000/api/patch-request?owner=timepassuser&repo=vuln_test"

# Configure Gemini key via API
curl -X POST http://localhost:8000/api/config/gemini-key \
     -H "Content-Type: application/json" \
     -d '{"key": "AIza..."}'

# Check if key is configured
curl http://localhost:8000/api/config/gemini-key
```

### Programmatic usage

```python
from vulnalyzer.graph.patch_request import generate_issue_body_with_ai

issue_md = generate_issue_body_with_ai(scan_result, use_ai=True, api_key="AIza...")
print(issue_md)
```
